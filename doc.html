1. Overview

wdPlayer is a lightweight, dependency-free HTML5 video player. The entire UI is built in JavaScript — just include one JS file and one CSS file on any page.

Auto Quality

Switches source based on measured bandwidth with hysteresis and upgrade cooldown.

ASS & VTT Subtitles

Native VTT subtitles and advanced ASS/SSA rendering via SubtitlesOctopus.

URL Encoding

Entire config is passed as a URL parameter — no backend required.

Thumbnail Preview

Hovering over the progress bar shows a live frame thumbnail and timestamp.

Playback Speed

0.5× to 2× — via the speed menu or keyboard shortcuts , / ..

Resume Playback

Position is saved to localStorage and a resume prompt is shown on next visit.

Fullscreen

Controls auto-hide after 2 seconds of inactivity when in fullscreen mode.

iframe Ready

embed.html is purpose-built for embedding via <iframe>.

2. Quick Start

The simplest way — open embed.html with the ?v= parameter: 

embed.html?v=https://example.com/video.mp4

The player detects the MIME type automatically from the file extension (.mp4, .webm, .ogv).

With multiple sources and subtitles

Use the URL Generator or encode manually: 

embed.html?sources=[
  {"label":"1080p","src":"https://…/1080.mp4","type":"video/mp4"},
  {"label":"720p", "src":"https://…/720.mp4", "type":"video/mp4"}
]&subtitles=[
  {"label":"English","src":"https://…/en.vtt","type":"vtt","srclang":"en"}
]
Note: when the URL contains ?sources=, the player automatically encodes it to ?v=BASE64 and redirects — you get a shorter, shareable link that works anywhere.

3. URL Parameters

Parameter Value Description
?v=URL https://…/video.mp4 Direct single-source shortcut. MIME type is inferred from the file extension.
?v=BASE64 URL-safe Base64 string Encoded config (sources + subtitles). Generated automatically or via the URL Generator.
?sources=JSON JSON array Raw sources as JSON. The player encodes and redirects to ?v=BASE64 automatically.
?subtitles=JSON JSON array Raw subtitles as JSON. Used together with ?sources=.

Source object

{
  "label": "1080p",           // displayed in the quality menu
  "src":   "https://…/v.mp4", // video URL
  "type":  "video/mp4"        // MIME type: video/mp4 | video/webm | video/ogg
}

Subtitle object

{
  "label":   "English",          // displayed in the subtitle menu
  "src":     "https://…/en.vtt", // subtitle file URL
  "type":    "vtt",              // "vtt" or "ass"
  "srclang": "en"                // optional: BCP 47 language code
}

4. Embedding (iframe)

The player is designed to be embedded via <iframe> using embed.html: 

<iframe
  src="embed.html?v=https://example.com/video.mp4"
  width="800"
  height="450"
  allowfullscreen
  style="border:none"
></iframe>

Responsive 16:9 container with CSS:

<div style="position:relative; padding-bottom:56.25%; height:0; overflow:hidden;">
  <iframe
    src="embed.html?v=BASE64"
    style="position:absolute; top:0; left:0; width:100%; height:100%; border:none;"
    allowfullscreen
  ></iframe>
</div>
Note: subtitle files must be served from the same origin or with appropriate CORS headers on the server.

5. Video Sources

You can provide multiple sources for different resolutions. The player shows them in the quality menu and automatically picks the best one based on measured bandwidth (Auto mode).

Supported formats

  • video/mp4 — H.264 or H.265 (HEVC, browser-dependent)
  • video/webm — VP8, VP9, AV1
  • video/ogg — Theora (.ogv)

Labels

The label field is shown in the quality button and menu. Recommended values: "1080p", "720p", "360p". Sources must be listed from highest quality to lowest. 

[
  {"label":"1080p","src":"https://…/1080.mp4","type":"video/mp4"},
  {"label":"720p", "src":"https://…/720.mp4", "type":"video/mp4"},
  {"label":"360p", "src":"https://…/360.mp4", "type":"video/mp4"}
]

6. Subtitles (VTT & ASS)

VTT (WebVTT)

Standard browser subtitle format. The player adds a native <track> element and renders subtitles using the browser's built-in engine. 

{"label":"English","src":"subtitles/en.vtt","type":"vtt","srclang":"en"}

ASS / SSA

Advanced format supporting custom styles, animations, and positioned text. Rendered via SubtitlesOctopus, which is lazy-loaded the first time an ASS track is selected. 

{"label":"English","src":"subtitles/en.ass","type":"ass","srclang":"en"}
Note: ASS rendering requires the following files to be present: js/octopus/subtitles-octopus.js, subtitles-octopus-worker.js, and subtitles-octopus-worker-legacy.js.

Multiple subtitle tracks

You can add as many subtitle tracks as needed — in different languages and formats: 

[
  {"label":"English (VTT)", "src":"sub/en.vtt","type":"vtt","srclang":"en"},
  {"label":"Lithuanian",    "src":"sub/lt.vtt","type":"vtt","srclang":"lt"},
  {"label":"English (ASS)", "src":"sub/en.ass","type":"ass","srclang":"en"}
]

7. Quality Control

Auto mode

When multiple sources are provided, the player automatically selects the best one based on measured bandwidth (Mbps). It uses:

  • navigator.connection.downlink — when supported by the browser
  • Timed fetch probe (~100 KB) — fallback method

Default thresholds (best → worst): [5 Mbps, 2 Mbps, …] — additional sources get interpolated thresholds.

Hysteresis & cooldown

  • Upgrading requires 20% more bandwidth than the threshold
  • Downgrading happens immediately when bandwidth drops 15% below the threshold
  • Upgrades cannot happen more than once every 10 seconds

Stall recovery

If the video buffers for more than 3 seconds while in Auto mode, the player automatically steps down one quality level.

Manual selection

Click the quality button in the control bar or press Q to cycle through available resolutions manually.

9. Controls Reference

  • ▶ / ⏸ Play/Pause — play or pause the video. The large central overlay button also works.
  • Timer — shows current position and total duration (0:00 / 5:24). Hours are included for videos longer than 1 hour.
  • Progress bar — click or drag to seek. Hovering shows a thumbnail preview and timestamp above the bar.
  • 🔊 Volume — mute toggle button + slider. Last setting is persisted in localStorage.
  • Auto / 720p (Quality) — only shown with multiple sources. Opens a menu with Auto and manual options.
  • CC (Subtitles) — only shown when at least one subtitle track has loaded. Menu lists all available tracks.
  • 1× (Speed) — playback speed menu: 0.5×, 0.75×, 1×, 1.25×, 1.5×, 2×.
  • ⛶ Fullscreen — enter or exit fullscreen mode.

Right-click context menu

Right-clicking anywhere on the player shows an info card with:

  • Player version
  • Active quality
  • Active subtitles
  • Video resolution (px)
  • Playback speed
  • Volume level

10. URL Generator

generator.html is a visual tool for building encoded player URLs without writing JSON by hand.

  1. Click + Add source and fill in the label, URL, and type.
  2. Optionally: click + Add subtitle and fill in the subtitle details.
  3. Click Generate URL.
  4. Copy the Encoded URL or the ready-made iFrame embed code.

Result tabs:

  • Encoded — full URL with ?v=BASE64
  • iFrame — ready-to-paste <iframe> HTML snippet
  • Raw — unencoded JSON config (useful for debugging)

12. Configuration (JS)

A small config block at the top of wdPlayer.js controls behaviour: 

// ─── Config ───────────────────────────────────────────────────────────────
const TOOLTIPS_ENABLED = true; // set false to disable button tooltips
// ──────────────────────────────────────────────────────────────────────────
Variable Default Description
TOOLTIPS_ENABLED true Show tooltips with keyboard hint above control buttons.
SPEED_RATES [0.5, 0.75, 1, 1.25, 1.5, 2] Array of speed options shown in the speed menu.
bandwidthThresholds [5, 2, …] Auto quality Mbps thresholds (computed automatically based on source count).
_UPGRADE_COOLDOWN_MS 10 000 Minimum milliseconds between quality upgrades.
_HYST_UP 1.2 Upgrading requires 20% more bandwidth than the threshold.
_HYST_DOWN 0.85 Downgrade when bandwidth falls 15% below the threshold.

localStorage keys

Key Description
wdPlayer:volume Last set volume level (0–1).
wdPlayer:muted "1" if muted, "0" if not.
wdPlayer:resume:<key> Last playback position in seconds. Key is the ?v= value or the source URL.
